Create your Discord bot

Conduit drives a Discord bot that you own. Create it and copy its token. Conduit checks the token with Discord and stores it encrypted on this PC. You'll need to be signed in to Discord in your browser.

  1. Open the Discord Developer Portal ▸ (sign in if asked).
  2. Click New Application, name it (e.g. Conduit) and click Create.
  3. In the left sidebar, open the Bot tab. If you see an Add Bot button, click it.
  4. Click Reset Token, confirm (complete 2FA if prompted), then click Copy. Discord shows a token only once.
  5. Paste it below. Copy the Token, not the Client Secret from the OAuth2 page.

Enable the Server Members Intent

Conduit requests the Server Members Intent, which lets the bot see your server's member list and keep up as people join, leave, or change roles. This is a privileged intent and is off by default — the bot can't log in without it.

  1. Stay on the Bot tab of your app.
  2. Scroll to Privileged Gateway Intents.
  3. Turn Server Members Intent ON.
  4. You can leave Presence and Message Content Intents off — Conduit doesn't use them.
  5. Scroll down and click Save Changes.

Then click "I've enabled it" below. Conduit checks it with Discord.

Invite the bot to your server

Click Continue to control this server.

This link is pre-filled with exactly the permissions Conduit needs: View Channels, Send Messages, Manage Messages, Embed Links, Attach Files, Read Message History, Mention Everyone, and Manage Channels.

Mention Everyone lets alarms ping @here or @everyone and your admin role. Manage Channels is used only to create Conduit's channels; you can remove it afterwards in your server's role settings.

  1. Open the invite link ▸
  2. Pick your server from the Add to Server dropdown. This first screen lists only "Add a bot to a server" and "Create commands" — that's expected; those are the access types, not the permission list. Click Continue.
  3. The next screen shows the eight permissions above as checkboxes. Keep them all ticked, then click Authorize (you must be a server admin).

Then click "I've invited the bot" below. Conduit finds your server by itself.

Invite it to a different server

Enter the Server ID manually instead

  1. In Discord, open User Settings → Advanced and turn on Developer Mode.
  2. Right-click your server's icon in the left bar and choose Copy Server ID.
  3. Paste it below.

Connect with Steam

Conduit registers with Rust+ using your Steam account — the same one you play Rust with. We open Facepunch's official login in a secure window; nothing is stored except the returned token.

  1. Click Connect Steam below.
  2. Sign in to Steam in the window that opens.
  3. Approve the login (check Steam Guard / your phone if prompted).
  4. The window closes itself when it's done.

Pair your server

Last connection step. You must be playing on the Rust server you want to control, and that server must have Rust+ enabled.

  1. Launch Rust and join the server you want to pair.
  2. Press Esc to open the in-game menu.
  3. Open the Rust+ section and click Pair with Server.
  4. Keep this window open — Conduit catches the pairing automatically.
